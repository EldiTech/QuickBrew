Need more help? The installation guide above covers the complete direct-download process.

Is this the official QuickBrew download?+

Yes. The APK on this page is the release package published for QuickBrew. You can compare its SHA-256 checksum with the value in the download section.

Why does Android mention unknown apps?+

Android shows that message for any app installed outside the Play Store. Allow the browser or file manager you used for this download, then continue the installation.

Which Android versions are supported?+

This release supports Android 7.0 and newer on ARMv7, ARM64, and x64 Android devices.

How do I update QuickBrew later?+

Return to this page when a new release is announced, download the latest APK, and install it over your current version.
